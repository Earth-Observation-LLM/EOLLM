\begin{frame}{The question}
\begin{itemize}
  \item Each sample pairs a \hl{marked satellite} image with a \hl{4-angle street-view} grid.
  \item For the \hl{9 urban-attribute tasks}, we ask: does the model actually \emph{need both views}?
  \item We compare four inputs --- \texttt{full} (both), \texttt{sat} only, \texttt{sv} only, \texttt{blind} (none) ---
        under \hl{three prompting strategies}, on the same records, greedy decoding.
\end{itemize}
\vfill
\footnotesize Cross-view tasks (\texttt{mismatch\_*}, \texttt{camera\_direction}) are excluded:
their answer lives in \emph{having both images}, so a single-view ablation is ill-posed there.
\end{frame}
\begin{frame}{Three strategies, same model}
\begin{description}
  \item[current] thinking off, one turn, ask directly. The baseline.
  \item[think16k] thinking \emph{on}, up to a 16k-token \texttt{<think>} budget, one turn.
  \item[multistep] thinking off, a 4-turn conversation: \emph{observe} each image $\to$
        \emph{reason} without options $\to$ \emph{self-check} $\to$ \emph{commit}. Turns uncapped.
\end{description}
\vfill
\centering\footnotesize \textbf{synergy} $=$ full $-\max(\text{sat},\text{sv})$ \quad
\textbf{vision} $=$ full $-$ blind
\end{frame}

\begin{frame}{Takeaway}
\begin{itemize}
  \item On all \hl{9 urbanization tasks}, across all \hl{3 strategies}, \texttt{full}
        never beats the best single view by a meaningful margin.
  \item The \hl{satellite view is redundant} given the street-view: \texttt{sv}-only
        matches or beats the two-view setup everywhere.
  \item Better prompting raises the ceiling (multistep $+3.1$ over baseline \texttt{full}),
        but it lifts \texttt{sv}-only \emph{in lockstep} --- the gap never closes.
  \item \hl{Conclusion:} for these tasks we do \emph{not} need both views. One well-chosen
        view (street-level) carries the signal; the second image does not earn its cost.
\end{itemize}
\end{frame}
